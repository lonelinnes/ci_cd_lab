# Changelog

## [1.1.0] - 2026-04-15
### Added
- Добавлена защита от ввода `qty <= 0` (возврат понятного `ValueError` вместо падения)
- Внедрено логирование с `%(asctime)s` для корректного аудита событий
- Добавлены `pytest`-тесты на нормальный и ошибочные сценарии

### Fixed
- Исправлено падение `KeyError` при запросе неизвестного товара (теперь ловится в `except` и логируется)
- Устранены синтаксические ошибки в основном цикле обработки (`elif`, `Exception`, `__name__`)

### Changed
- Обновлена версия модуля до `1.1.0`
- Улучшена структура вывода отчёта в консоли
